# External executable

Install AutoDock Vina separately. Put `vina.exe` here on Windows or a Linux executable named `vina` on Linux. Vina 1.2.7 was used for the technical check. Configure the path in `app_settings.json` or pass `--vina` with `--run`/`--check`. A Windows binary cannot serve as a native Linux cluster executable. Binary redistribution requires preserving the applicable licenses and notices.
