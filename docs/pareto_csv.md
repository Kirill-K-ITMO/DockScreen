# Отбор Парето через CSV

Необязательный режим **Парето + SMAA** использует тот же CSV и отдельный JSON
шкал/предпочтений: пункт 16, `--smaa-template` и `--smaa-run`. Он ранжирует весь
допустимый набор по сценариям предпочтений без новых docking/ADMET. Режим ниже
«только Парето» сохраняется. См. [инструкцию SMAA](smaa.md).

Докинг и ADMET выполняются один раз. Последующие изменения критериев не требуют
новых предсказаний. Откройте пункт **15** основного меню и выберите завершённый запуск.
Программа подготовит два файла в папке `settings/`:

- **settings/PARETO_CRITERIA.csv** — короткий редактируемый набор критериев.
- **settings/PARETO_PARAMETERS.csv** — каталог всех доступных параметров с пояснениями.

В первый раз нажмите Enter для выхода из настройки. Откройте CSV в Excel,
LibreOffice или текстовом редакторе, отредактируйте и сохраните **CSV UTF-8**.
Разделитель создаваемого файла — точка с запятой. Если Excel открывает всё одним
столбцом, используйте импорт «Из текста/CSV» и выберите UTF-8 и `;`. При чтении
поддерживаются также запятая и табуляция; десятичная запятая внутри числа допустима
в корректно разделённом/заключённом в кавычки CSV. Не используйте разделители тысяч.

Потом снова запустите пункт 15, выберите запуск и введите **1** для
применения сохранённого файла. Путь к другому CSV можно указать отдельно.
Выберите одну мишень/профиль и конкретный протокол по номеру из списка.
Оригинальные файлы запусков и предсказаний не перезаписываются.

## Столбцы настроек

| Столбец | Что вписывать |
|---|---|
| Параметр | Точный ID из каталога, например `DILI`. Не переводите/не переименовывайте ID. |
| Использование | `сравнивать` — цель Парето; `ограничение` — только отсев; `не учитывать` — полностью отключить строку. |
| Направление | Для сравнения: `минимум`, `максимум` либо `диапазон`. Для ограничения оставьте пустым. |
| Не ниже | Нижняя допустимая граница. Пусто — нижней границы нет. |
| Не выше | Верхняя допустимая граница. Пусто — верхней границы нет. |
| Цель от / Цель до | Только для направления `диапазон`: желаемый интервал. За выход из него кандидат получает расстояние до интервала, но не исключается. |
| Пояснение | Справочный текст, не влияет на вычисления. |

Шаблон user-default-v3 содержит пять целей:
докинг ≤−7 — минимум, DILI ≤0.5 — минимум, ClinTox ≤0.5 — минимум,
Bioavailability_Ma ≥0.5 — максимум (модельная оценка, не процент), hERG ≤0.5 — минимум.
Для полного автоматического набора требуются все пять показателей. Если
обязательный endpoint недоступен, программа не подменяет набор сокращённым.
Это редактируемый пример, не универсальная схема отбора лекарства.

Чтобы добавить любой другой параметр, скопируйте его строку из каталога в
settings/PARETO_CRITERIA.csv и измените `Использование`. Чтобы отключить параметр,
достаточно написать `не учитывать`; остальные ячейки этой строки игнорируются.
Неуказанные параметры тоже не участвуют. Один ID не может встречаться дважды.

Пример CSV (в файле UTF-8):

```csv
Параметр;Использование;Направление;Не ниже;Не выше;Цель от;Цель до;Пояснение
docking_score;сравнивать;минимум;;;;;Модельная оценка докинга
DILI;ограничение;;;0.5;;;Сценарная граница не клинический норматив
logP;сравнивать;диапазон;;;1;3;Желаемый диапазон 1–3
```

Равенство допустимой границе проходит. Пропуск активного значения исключает
кандидата с объяснением; пропуск не превращается в ноль. Сначала применяются
ограничения, затем точное недоминирование по всем целям. Равные кандидаты
сохраняются. Веса и общий суммарный балл не используются. Если заданы только
ограничения, программа выгружает прошедших кандидатов, но не объявляет фронт.
Нужна хотя бы одна цель или ограничение.

После согласия на ADMET в конце интерактивного докинга автоматически применяется
стартовый набор **user-default-v3**: докинг ≤−7 ↓, DILI ≤0.5 ↓,
ClinTox ≤0.5 ↓, Bioavailability_Ma ≥0.5 ↑, hERG ≤0.5 ↓. Для каждой мишени/профиля/протокола создаётся отдельный
отбор. Его CSV имеет имя `user-default-v3-<hash>.csv`, а индекс результатов —
`pareto/default_selections.json`. Если все строки исключены, границы не ослабляются.
Это не стандарт пригодности лекарства. Пользовательский settings/PARETO_CRITERIA.csv
сохраняется; для применения изменённого файла используйте пункт 15.

Знак оценки докинга согласован явно: −8 проходит границу ≤−7, −6 исключается;
ровно−7 проходит. Равенство 0.5 для DILI/ClinTox/hERG и 0.5 для Bioavailability_Ma
тоже проходит. Старый exploratory-v1 остаётся только в ранее сохранённых отборах.

## Результат

Каждое применение создаёт новую папку `output/runs/ИМЯ/pareto/selection-.../`:

- **front.csv** — фронт Парето;
- **feasible.csv** — все прошедшие ограничения;
- **all_candidates.csv** — все строки, причины исключения и номера доминаторов;
- **criteria.csv** — точная копия применённого входного CSV;
- **settings.json / selection.json** — настройки, протокол, хэши источников,
  метаданные модели и исходные значения/SMILES;
- **report.html** — простой отчёт для просмотра без полей ввода. Проекция по двум
  параметрам показывает фронт, рассчитанный по всем целям.

Раздел «Структуры кандидатов фронта» содержит досье: название, сохранённый SMILES,
изображение, docking score, DILI, ClinTox и Bioavailability_Ma. Дополнительные
сигналы hERG/AMES раскрываются отдельно, если они доступны. Пропуски подписаны
«нет значения», ноль остаётся нулём. Числа в карточках округлены; точные значения
доступны в подсказке и CSV/JSON. Модельные оценки не являются клиническими рисками
или процентом биодоступности. Поля выбора целей/ограничений остаются в CSV.

Итоговые CSV защищают формульные строки апострофом; исходные имена сохраняются
в JSON. Файлы `*.csv.notes.json` содержат метаданные экспортов, переносите их
вместе с CSV. При экспорте ZIP содержимое pareto/ также включается.

## Команды без меню

```powershell
.\.venv\Scripts\python.exe main.py --pareto-template output/runs/ИМЯ
.\.venv\Scripts\python.exe main.py --pareto-run output/runs/ИМЯ --pareto-criteria output/runs/ИМЯ/pareto_criteria.csv --pareto-target JAK1_3EYG
```

Если у мишени несколько протоколов, дополнительно укажите `--pareto-protocol ID`.
Меню всегда предлагает явный выбор протокола. Оценки разных мишеней не усредняются.
Параметры модели не являются доказанной активностью/безопасностью; DILI и
Bioavailability_Ma — выходы классификаторов, не клинические вероятности и не
процент биодоступности. Индивидуальная неопределённость не оценена. SMAA доступен отдельным действием, см. [инструкцию](smaa.md).

Автоматические HTML и схема имён документов описаны в [основном руководстве](../README_RU.md#html-и-понятные-имена-документов).
